# DEM Claim-Status Ledger

DEM uses explicit epistemic labels so that established physics, reinterpretation, postulate, hypothesis, and proposed tests do not blur together.

| Tag | Meaning | Standard |
|---|---|---|
| **E** | Established physics / mathematics | Supported by standard theory and/or experiment within the stated domain. |
| **C** | Science-compatible reinterpretation | Changes explanatory or ontological language without yet changing tested predictions. |
| **P** | Working postulate | Provisionally adopted to construct the framework; revisable. |
| **H** | Hypothesis | Requires mathematical derivation and/or empirical evidence. |
| **T** | Proposed test / discriminant | Intended to generate evidence for, against, or between models. |

## Discipline

A DEM proposal is not upgraded because it is elegant or intuitive. It earns stronger status only through one or more of:

- derivation from fewer assumptions;
- recovery of established quantitative results;
- a coordinate-invariant mathematical consequence;
- a falsifiable prediction;
- replicated empirical evidence.

When a claim changes status, update this ledger and document why.
