# Differentiated Existence Model (DEM)

This repository develops the **Differentiated Existence Model**, a foundational research framework that begins with existence and differentiation, then asks which familiar structures of physics must be fundamental and which may instead be resolution-dependent or emergent.

> **Status:** early research program. DEM is not a peer-reviewed or experimentally confirmed physical theory.

The project is intentionally conservative about claims: established physics is treated as a hard compatibility requirement, speculative ideas are labeled as such, and useful progress must eventually produce derivations, invariant observables, or falsifiable predictions.
